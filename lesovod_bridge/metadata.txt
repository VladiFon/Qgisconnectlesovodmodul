description=Публикация контуров лесосек из базы ГИСлесхоз (RUP «Белгослес») в систему «Лесовод». Только чтение базы ГИСлесхоз, ничего в ней не меняет.
about=Своя панель инструментов «Лесовод-мост»: «Что здесь» (характеристики участка лесных культур, делянки, обмера, метки по щелчку — независимо от активного слоя), поиск «кв выд», слои Лесовода, отметка л/к, раскраска, публикация, выгрузка shp. Отдельный вспомогательный плагин рядом с официальным плагином ГИСлесхоз. Не редактирует и не встраивается в его код. Читает таблицу area в базе ГИСлесхоз (PostgreSQL/PostGIS) в режиме только для чтения и отправляет контуры лесосек в «Лесовод» (по пачке на лесничество, layer_name = "лесосеки_qgis"), полностью заменяя прежние. Добавляет в QGIS слои с сервера: метки рабочих с фото, делянки с легендой по статусу / виду рубки (ССР, УЗ, ПРЖ…) / виду пользования, лесные культуры по виду, обмеры с телефона. Отмечает выделенные полигоны как лесные культуры (вид, год, порода) — участок с контуром создаётся в «Лесоводе». Раскрашивает слой «Лесосеки» ГИСлесхоза по виду рубки или виду пользования (только стиль в проекте, база не меняется). Выгружает выбранные лесосеки (фильтр по лесничеству, кварталу, году, виду рубки, поиск) в shp с .prj для текущих изменений.
